# 概述 {#overview}

本节包含正在考虑纳入 AG-UI 协议的草案变更。这些提案正在内部评审中，可能在实现之前被修改或撤回。

## 当前草案 {#current-drafts}

- [推理](https://docs.ag-ui.com/drafts/reasoning) — 支持 LLM 推理的可见性，以及基于加密内容的推理连续性

  
  - [中断感知的运行生命周期](../concepts/interrupts.md) — 原生支持需要人工批准或输入而暂停的智能体

  - [生成式用户界面](./generative-ui.md) — 无需自定义工具渲染器即可生成 AI 界面

  - [元事件](./meta-events.md) — 独立于智能体运行的注解与信号

## 状态定义 {#status-definitions}

- **草案** - 正在考虑的初始提案
- **评审中** - 正在积极开发与测试
- **已接受** - 已批准实现
- **已实现** - 已合并到主协议规范
- **已撤回** - 提案已被撤回或被取代
