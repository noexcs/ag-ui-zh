# 命名约定 {#naming-conventions}

将你的包添加到 `integrations/` 下，并附上文档与测试。

如果你的集成尚在开发中，你仍然可以将其添加到 main 分支。
你可以为其加上 `wip-` 前缀，即
（`integrations/wip-your-integration`），如果你是第三方
贡献者，则使用 `community` 前缀，即
（`integrations/community/your-integration`）。

如有问题与讨论，请使用
[GitHub Discussions](https://github.com/ag-ui-protocol/ag-ui/discussions)。
