<em class="lead">面向使用 AG-UI 构建者的开源与社区支持</em>

AG-UI 是免费且开源的。请使用项目的公开支持渠道来
报告问题、提出改进建议、参与贡献，或从
社区获取帮助。

- [缺陷、功能请求与贡献](https://github.com/ag-ui-protocol/ag-ui/issues) — 在 GitHub 上报告问题、提出改进建议或为 AG-UI 贡献代码。

  - [社区提问与讨论](https://discord.gg/Jd3FzfdJa8) — 在 Discord 上提问，并向其他使用 AG-UI 构建的人学习。
